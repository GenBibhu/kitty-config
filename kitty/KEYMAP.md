# Kitty Keymap

Modifier: `Ctrl+Shift`

Kitty now opens as a maximized normal window, not exclusive fullscreen.

## Windows and Splits

- `Ctrl+Shift+Enter`: automatic split, new shell in the current directory
- `Ctrl+Shift+\`: vertical split, new shell on the side
- `Ctrl+Shift+-`: horizontal split, new shell above/below
- `Ctrl+Shift+W`: close window
- `Ctrl+Shift+Space`: next layout
- `Ctrl+Shift+Z`: toggle stack layout

## Focus

- `Ctrl+Shift+H/J/K/L`: move focus left/down/up/right
- `Ctrl+Shift+Arrow`: move focus left/down/up/right

## Move and Resize

- `Ctrl+Shift+Alt+H/J/K/L`: move window left/down/up/right
- `Ctrl+Shift+Alt+Arrow`: move window left/down/up/right
- `Ctrl+Shift+R`: interactive resize mode
- `Ctrl+Shift+Alt+=`: wider
- `Ctrl+Shift+Alt+-`: narrower

## Move Kitty Between Monitors

These are GNOME global shortcuts. They move the whole Kitty app window, not an
internal Kitty tile.

- `Super+Shift+H` or `Super+Shift+Left`: move Kitty to the monitor on the left
- `Super+Shift+L` or `Super+Shift+Right`: move Kitty to the monitor on the right
- `Super+Shift+K` or `Super+Shift+Up`: move Kitty to the monitor above
- `Super+Shift+J` or `Super+Shift+Down`: move Kitty to the monitor below

## Tabs

- `Ctrl+Shift+T`: new tab in the current directory
- `Ctrl+Shift+Q`: close tab
- `Ctrl+Shift+]`: next tab
- `Ctrl+Shift+[`: previous tab
- `Ctrl+Shift+.`: move tab forward
- `Ctrl+Shift+,`: move tab backward
- `Ctrl+Shift+1..0`: jump to tab 1..10
- `Ctrl+Shift+E`: rename tab

## Search, Hints, Clipboard

- `Ctrl+Shift+F`: search scrollback
- `Ctrl+Shift+G`: open scrollback
- `Ctrl+Shift+U`: open URL hints
- `Ctrl+Shift+P`: path hints
- `Ctrl+Shift+Y`: line hints
- `Ctrl+Shift+C`: copy
- `Ctrl+Shift+V`: paste clipboard
- `Ctrl+Shift+S`: paste selection

## Font Size

- `Ctrl+Shift+=`: increase font size
- `Ctrl+Shift+Backspace`: decrease font size
- `Ctrl+Shift+Alt+0`: reset font size
